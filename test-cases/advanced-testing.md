# Расширенное тестирование SauceDemo (Security, A11y, UI)

##  Безопасность (Basic Security)

### TC-36: Проверка обработки SQL-инъекции в поле Username

| Поле | Значение |
|------|----------|
| **ID** | TC-36 |
| **Название** | Проверка обработки SQL-инъекции в поле Username |
| **Предусловие** | Открыта страница авторизации https://www.saucedemo.com/ |
| **Шаги** | 1. Ввести `' OR 1=1 --` в поле Username<br>2. Ввести `secret_sauce` в поле Password<br>3. Нажать кнопку «Login»<br>4. Проверить результат авторизации и отображаемое сообщение |
| **Ожидаемый результат** | Авторизация не выполняется. Пользователь остаётся на странице входа. Отображается штатное сообщение об ошибке авторизации. SQL-код не приводит к обходу авторизации или отображению технических ошибок базы данных. |
| **Статус** | Not Run |

### TC-37: Проверка обработки XSS в поле First Name при оформлении заказа

| Поле | Значение |
|------|----------|
| **ID** | TC-37 |
| **Название** | Проверка обработки XSS в поле First Name при оформлении заказа |
| **Предусловие** | Пользователь `standard_user` авторизован, в корзине находится хотя бы один товар |
| **Шаги** | 1. Открыть корзину<br>2. Нажать кнопку «Checkout»<br>3. В поле First Name ввести `<script>alert('XSS')</script>`<br>4. Заполнить Last Name и Zip/Postal Code валидными данными<br>5. Нажать кнопку «Continue»<br>6. Проверить отображение введённого значения на странице подтверждения заказа |
| **Ожидаемый результат** | JavaScript-код не выполняется. Всплывающее окно `alert` не появляется. Введённое значение не приводит к выполнению скрипта в браузере. |
| **Статус** | Not Run |

##  Доступность (Accessibility / A11y)

| **Поле**                | **Значение** |
| ----------------------- | ------------ |
| **ID**                  | TC-38 |
| **Название**            | Проверка доступности формы авторизации без использования мыши |

| **Шаги**                | 1. Нажать клавишу `Tab` и проверить, что фокус перешёл на поле Username<br>2. Ввести логин `standard_user`<br>3. ### TC-39: Проверка наличия альтернативного текста у изображений товаров

| **Поле**                | **Значение** |
| ----------------------- | ------------ |
| **ID**                  | TC-39 |
| **Название**            | Проверка наличия корректного атрибута alt у изображений товаров |
| **Предусловие**         | Пользователь авторизован, открыта страница каталога товаров |
| **Шаги**                | 1. Открыть Chrome DevTools (`F12`)<br>2. Перейти во вкладку Elements<br>3. Найти HTML-элемент `<img>` одного из товаров<br>4. Проверить наличие атрибута `alt`<br>5. Проверить содержимое атрибута `alt` |
| **Ожидаемый результат** | У изображений товаров присутствует атрибут `alt`. Его значение содержит осмысленное текстовое описание изображения, позволяющее определить соответствующий товар. |
| **Статус**              | Fail (см. BUG-11) |


##  Адаптивность и UI (Responsive)


### TC-40: Проверка отображения корзины на мобильном разрешении 375×812

| **Поле**                | **Значение** |
| ----------------------- | ------------ |
| **ID**                  | TC-40 |
| **Название**            | Проверка адаптивности страницы корзины на разрешении 375×812 (iPhone X) |
| **Предусловие**         | Пользователь авторизован, в корзине находится хотя бы один товар |
| **Шаги**                | 1. Открыть Chrome DevTools (`F12`)<br>2. Включить режим эмуляции мобильного устройства (`Ctrl+Shift+M`)<br>3. Выбрать устройство iPhone X с разрешением 375×812<br>4. Открыть страницу корзины<br>5. Проверить отображение названий товаров, цен и количества<br>6. Проверить расположение кнопок «Remove» и «Checkout»<br>7. Проверить наличие горизонтальной прокрутки |
| **Ожидаемый результат** | Элементы корзины отображаются корректно и не выходят за границы экрана. Кнопки «Remove» и «Checkout» полностью видны и доступны для нажатия. Текст читаемый. Отсутствует нежелательная горизонтальная прокрутка. |
| **Статус**              | Fail (см. BUG-12) |



### TC-41: Проверка защиты сессии после выхода из системы

| **Поле**                | **Значение** |
| ----------------------- | ------------ |
| **ID**                  | TC-41 |
| **Название**            | Проверка невозможности доступа к каталогу после выхода из системы |
| **Предусловие**         | Пользователь авторизован под учётной записью `standard_user`, открыта страница каталога товаров |
| **Шаги**                | 1. Открыть меню навигации<br>2. Нажать кнопку «Logout»<br>3. Убедиться, что отображается страница авторизации<br>4. Нажать кнопку «Назад» в браузере<br>5. Проверить доступность страницы каталога<br>6. Если каталог отображается, обновить страницу и проверить результат |
| **Ожидаемый результат** | После выхода из системы пользователь не может получить доступ к защищённой странице каталога. При попытке вернуться к каталогу происходит перенаправление на страницу авторизации либо отображается страница входа после обновления. Повторная авторизация необходима для доступа к каталогу. |
| **Статус**              | Pass |
