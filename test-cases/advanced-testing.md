|---|---|

## 4. Безопасность сессии (Session Security)

### TC-41: Проверка защиты сессии после выхода из системы

| Поле | Значение |
|---|---|
| ID | TC-41 |
| Название | Проверка невозможности доступа к каталогу после выхода из системы |
| Предусловие | Пользователь авторизован под учётной записью `standard_user`, открыта страница каталога товаров. |
| Шаги | 1. Открыть меню навигации.<br>2. Нажать Logout.<br>3. Убедиться, что отображается страница авторизации.<br>4. Нажать кнопку Назад в браузере.<br>5. Проверить доступность страницы каталога.<br>6. Если каталог отображается, обновить страницу и проверить результат. |
| Ожидаемый результат | После выхода из системы пользователь не может получить доступ к защищённой странице каталога. При попытке вернуться к каталогу происходит перенаправление на страницу авторизации либо отображается страница входа после обновления. Повторная авторизация необходима для доступа к каталогу. |
| Статус | Pass |
