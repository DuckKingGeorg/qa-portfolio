# Расширенное тестирование SauceDemo (Security, A11y, UI)

##  Безопасность (Basic Security)

### TC-36: Проверка на SQL-инъекцию в поле логина
| Поле | Значение |
|------|----------|
| **ID** | TC-36 |
| **Название** | Проверка устойчивости формы авторизации к SQL-инъекциям |
| **Предусловие** | Открыта страница авторизации |
| **Шаги** | 1. Ввести `' OR 1=1 --` в поле Username<br>2. Ввести любой пароль<br>3. Нажать «Login» |
| **Ожидаемый результат** | Вход не выполнен. Появляется стандартное сообщение об ошибке (Username and password do not match). Система не выдает ошибок базы данных. |
| **Статус** | Pass |

### TC-37: Проверка на XSS (Cross-Site Scripting) при оформлении заказа
| Поле | Значение |
|------|----------|
| **ID** | TC-37 |
| **Название** | Проверка защиты от XSS при вводе имени в форму Checkout |
| **Предусловие** | Пользователь авторизован, товар в корзине, открыта форма Checkout |
| **Шаги** | 1. В поле First Name ввести `<script>alert('XSS')</script>`<br>2. Заполнить остальные поля и нажать «Continue»<br>3. Перейти к подтверждению заказа |
| **Ожидаемый результат** | Скрипт не выполняется (нет всплывающего окна). Текст отображается как обычная строка или форма выдает ошибку валидации. |
| **Статус** | Pass |

##  Доступность (Accessibility / A11y)

### TC-38: Навигация по форме логина с клавиатуры
| Поле | Значение |
|------|----------|
| **ID** | TC-38 |
| **Название** | Проверка доступности формы авторизации без использования мыши |
| **Предусловие** | Открыта страница авторизации |
| **Шаги** | 1. Нажать клавишу `Tab` (фокус должен перейти на поле Username)<br>2. Ввести логин<br>3. Нажать `Tab` (фокус на поле Password)<br>4. Ввести пароль, нажать `Tab`, затем `Enter` |
| **Ожидаемый результат** | Все интерактивные элементы доступны через Tab. Фокус визуально подсвечивается. Вход выполняется нажатием Enter. |
| **Статус** | Pass |

### TC-39: Наличие атрибутов alt у изображений товаров
| Поле | Значение |
|------|----------|
| **ID** | TC-39 |
| **Название** | Проверка наличия текстового описания (alt) для картинок товаров |
| **Предусловие** | Пользователь авторизован, находится в каталоге |
| **Шаги** | 1. Открыть Chrome DevTools (Elements)<br>2. Найти тег `<img>` любого товара<br>3. Проверить наличие атрибута `alt` |
| **Ожидаемый результат** | У всех изображений есть атрибут `alt` с названием товара (для скринридеров). |
| **Статус** | Fail (см. BUG-11) |

##  Адаптивность и UI (Responsive)

### TC-40: Отображение корзины на экране мобильного телефона
| Поле | Значение |
|------|----------|
| **ID** | TC-40 |
| **Название** | Проверка юзабилити корзины на разрешении 375x812 (iPhone X) |
| **Предусловие** | Пользователь авторизован, в корзине есть товары |
| **Шаги** | 1. Открыть DevTools -> Toggle device toolbar (Ctrl+Shift+M)<br>2. Выбрать iPhone X<br>3. Перейти в корзину и проверить отображение элементов |
| **Ожидаемый результат** | Кнопки «Remove» и «Checkout» полностью видны, не перекрывают друг друга, шрифт читаемый, нет горизонтальной прокрутки. |
| **Статус** | Fail (см. BUG-12) |

### TC-41: Поведение сессии при нажатии кнопки «Назад» после Logout
| Поле | Значение |
|------|----------|
| **ID** | TC-41 |
| **Название** | Проверка защиты сессии после выхода из системы |
| **Предусловие** | Пользователь авторизован, находится в каталоге |
| **Шаги** | 1. Нажать «Logout» (бургер-меню)<br>2. Оказаться на странице логина<br>3. Нажать кнопку «Назад» в браузере |
| **Ожидаемый результат** | Пользователь не попадает обратно в каталог. Происходит редирект на страницу логина (сессия уничтожена). |
| **Статус** | Pass |
