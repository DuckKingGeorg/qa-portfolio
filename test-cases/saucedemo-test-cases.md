# Тест-кейсы для SauceDemo — Авторизация

## TC-01: Успешный вход с валидными данными

| Поле | Значение |
|------|----------|
| **ID** | TC-01 |
| **Название** | Успешный вход с валидными данными |
| **Предусловие** | Открыта страница https://www.saucedemo.com/ |
| **Шаги** | 1. Ввести `standard_user` в поле Username<br>2. Ввести `secret_sauce` в поле Password<br>3. Нажать кнопку «Login» |
| **Ожидаемый результат** | Пользователь перенаправлен на страницу каталога товаров (Inventory). В URL появляется `/inventory.html`. Отображается список товаров. |
| **Статус** | Pass |
