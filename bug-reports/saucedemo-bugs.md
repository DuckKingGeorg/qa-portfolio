# Баг-репорты для SauceDemo


## BUG-01: Изображения товаров не соответствуют названиям у problem_user

| **Поле**                  | **Значение** |
| ------------------------- | ------------ |
| **ID**                    | BUG-01 |
| **Заголовок**             | Изображения товаров не соответствуют названиям у пользователя `problem_user` |
| **Проект**                | SauceDemo |
| **Окружение**             | Браузер: Chrome 120; ОС: Windows 10; URL: https://www.saucedemo.com/ |
| **Предусловие**           | Открыта страница авторизации, есть доступ к аккаунтам `standard_user` и `problem_user` |
| **Шаги воспроизведения**  | 1. Войти под учётной записью `standard_user` с паролем `secret_sauce`<br>2. Проверить соответствие изображений названиям товаров в каталоге<br>3. Выйти из аккаунта через меню навигации → Logout<br>4. Войти под учётной записью `problem_user` с паролем `secret_sauce`<br>5. Проверить соответствие изображений названиям товаров в каталоге<br>6. Сравнить изображения одних и тех же товаров у обоих пользователей |
| **Ожидаемый результат**   | Изображение каждого товара соответствует его названию. Изображения одинаковых товаров не различаются при входе под `standard_user` и `problem_user`. |
| **Фактический результат** | У пользователя `problem_user` у всех товаров отображается одно и то же изображение собаки, которое не соответствует названиям товаров. У пользователя `standard_user` изображения отображаются корректно. |
| **Severity**              | Medium |
| **Priority**              | Medium |
| **Воспроизводимость**     | 100% (всегда) |
| **Дополнительно**         | Дефект специфичен для пользователя `problem_user`. Связан с BUG-06 (подмена данных товара) и BUG-07 (ITEM NOT FOUND). |



## BUG-02: Опции сортировки не выбираются и не применяются у problem_user

| **Поле**                  | **Значение** |
| ------------------------- | ------------ |
| **ID**                    | BUG-02 |
| **Заголовок**             | Опции сортировки не применяются у пользователя `problem_user` |
| **Проект**                | SauceDemo |
| **Окружение**             | Браузер: Chrome 120; ОС: Windows 10; URL: https://www.saucedemo.com/ |

Убедиться, что отображаются четыре опции: Name (A to Z), Name (Z to A), Price (low to high), Price (high to low)<br>3. Выбрать опцию Name (A to Z)<br>4. Проверить выбранную опцию и порядок отображения товаров<br>5. Повторить проверку для остальных трёх опций сортировки |
