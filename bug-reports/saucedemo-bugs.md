# Баг-репорты для SauceDemo

## BUG-01: Изображения товаров не соответствуют названиям у problem_user

| Поле | Значение |
|------|----------|
| **ID** | BUG-01 |
| **Заголовок** | Изображения товаров не соответствуют названиям у пользователя problem_user |
| **Проект** | SauceDemo |
| **Окружение** | Браузер: Chrome 120; ОС: Windows 10; URL: https://www.saucedemo.com/ |
| **Предусловие** | Открыта страница авторизации, есть доступ к аккаунтам `standard_user` и `problem_user` |
| **Шаги воспроизведения** | 1. Войти как `standard_user` / `secret_sauce`<br>2. Запомнить, как выглядят изображения товаров<br>3. Выйти (бургер → Logout)<br>4. Войти как `problem_user` / `secret_sauce`<br>5. Сравнить изображения товаров с их названиями и с тем, что было у `standard_user` |
| **Ожидаемый результат** | У каждого товара уникальное изображение, соответствующее названию. Изображения идентичны тем, что видны у `standard_user` |
| **Фактический результат** | У всех товаров отображается одно и то же изображение (собака/несоответствующая картинка). Изображения не соответствуют названиям |
| **Severity** | Medium |
| **Priority** | Medium |
| **Воспроизводимость** | 100% (всегда) |
| **Дополнительно** | Баг специфичен только для `problem_user`. У `standard_user` изображения корректны. Связан с BUG-06 (подмена данных товара) и BUG-07 (ITEM NOT FOUND) — из-за одинаковых изображений невозможно визуально идентифицировать товар |
