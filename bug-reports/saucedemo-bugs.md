# Баг-репорты для SauceDemo

## BUG-01: Изображения товаров не соответствуют названиям у problem_user

| Поле | Значение |
|------|----------|
| **ID** | BUG-01 |
| **Заголовок** | Изображения товаров не соответствуют названиям у пользователя problem_user |
| **Проект** | SauceDemo |
| **Окружение** | Браузер: Chrome 120; ОС: Windows 10; URL: https://www.saucedemo.com/ |
| **Предусловие** | Открыта страница авторизации, есть доступ к аккаунтам `standard_user` и `problem_user` |
| **Шаги воспроизведения** | 1. Войти как `standard_user` / `secret_sauce`<br>2. Запомнить, как выглядят изображения товаров (рюкзак, фонарь, футболка, куртка, комбинезон)<br>3. Выйти из аккаунта (бургер → Logout)<br>4. Войти как `problem_user` / `secret_sauce`<br>5. Сравнить изображения товаров с их названиями и с тем, что было у `standard_user` |
| **Ожидаемый результат** | У каждого товара уникальное изображение, соответствующее названию. Изображения идентичны тем, что видны у `standard_user` |
| **Фактический результат** | У всех товаров отображается одно и то же изображение (собака/несоответствующая картинка). Изображения не соответствуют названиям товаров |
| **Severity** | Medium |
| **Priority** | Medium |
| **Воспроизводимость** | 100% (всегда) |
| **Дополнительно** | Баг специфичен только для пользователя `problem_user`. У `standard_user` изображения корректны |

## BUG-02: Сортировка товаров не работает у problem_user

| Поле | Значение |
|------|----------|
| **ID** | BUG-02 |
| **Заголовок** | Сортировка товаров по имени и цене не применяется у пользователя problem_user |
| **Проект** | SauceDemo |
| **Окружение** | Браузер: Chrome 120; ОС: Windows 10; URL: https://www.saucedemo.com/ |
| **Предусловие** | Пользователь `problem_user` авторизован, находится на странице каталога `/inventory.html` |
| **Шаги воспроизведения** | 1. Открыть выпадающий список сортировки в правом верхнем углу<br>2. Убедиться, что список открывается и видны опции: «Name (A to Z)», «Name (Z to A)», «Price (low to high)», «Price (high to low)»<br>3. Кликнуть на опцию «Name (A to Z)»<br>4. Проверить, изменился ли порядок товаров<br>5. Повторить для остальных опций |
| **Ожидаемый результат** | При клике на опцию она выбирается (отображается как активная), порядок товаров меняется согласно выбранной сортировке. Поведение идентично `standard_user` |
| **Фактический результат** | Список открывается, но при клике на любую опцию выбор не фиксируется — опция не применяется, порядок товаров остаётся исходным. Ни одна из четырёх опций не работает |
| **Severity** | Medium |
| **Priority** | High |
| **Воспроизводимость** | 100% (всегда) |
| **Дополнительно** | Баг специфичен только для `problem_user`. У `standard_user` сортировка работает корректно. Затрагивает все 4 опции сортировки |

## BUG-03: Неинформативное сообщение об ошибке для заблокированного пользователя locked_out_user

| Поле | Значение |
|------|----------|
| **ID** | BUG-03 |
| **Заголовок** | Сообщение об ошибке при входе locked_out_user не объясняет причину блокировки и способ её снятия |
| **Проект** | SauceDemo |
| **Окружение** | Браузер: Chrome 120; ОС: Windows 10; URL: https://www.saucedemo.com/ |
| **Предусловие** | Открыта страница авторизации https://www.saucedemo.com/ |
| **Шаги воспроизведения** | 1. Ввести `locked_out_user` в поле Username<br>2. Ввести `secret_sauce` в поле Password<br>3. Нажать кнопку «Login»<br>4. Прочитать появившееся сообщение об ошибке |
| **Ожидаемый результат** | Понятное сообщение с указанием причины блокировки (например, «Ваш аккаунт заблокирован администратором») и рекомендацией, что делать дальше (связаться с поддержкой, восстановить доступ и т.д.) |
| **Фактический результат** | Отображается сообщение «Sorry, this user has been locked out» без объяснения причины и без указания дальнейших действий. Пользователь не понимает, что произошло и как это исправить |
| **Severity** | Low |
| **Priority** | Low |
| **Воспроизводимость** | 100% (всегда) |
| **Дополнительно** | Формально вход заблокирован корректно (это ожидаемое поведение), но текст сообщения можно улучшить с точки зрения UX. Баг не блокирующий, но влияет на пользовательский опыт |
