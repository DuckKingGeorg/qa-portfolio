**Тестовая документация:** тест-кейсы, чек-листы, баг-репорты.

**Инструменты:** Postman, Chrome DevTools, Git, GitHub, Jira — начальный уровень знакомства и учебная практика.

**Техническая база:** основы HTTP, REST API и JSON; начальное изучение SQL.

**Автоматизация:** основы Python; учебная практика написания API-тестов с использованием Pytest и Requests.
