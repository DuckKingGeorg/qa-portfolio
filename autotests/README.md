# Автотесты API на Python

Простые автоматизированные тесты для проверки REST API [JSONPlaceholder](https://jsonplaceholder.typicode.com/) с использованием Python, `pytest` и `requests`.

## Что проверяют тесты

1. `test_get_post_by_id` — получение поста по ID, проверка статуса 200 и наличия необходимых полей.
2. `test_get_all_posts` — получение списка постов, проверка статуса 200 и количества элементов (100).
3. `test_create_post` — отправка POST-запроса, проверка статуса 201 и данных в ответе.
4. `test_get_non_existent_post` — негативный тест: проверка статуса 404 для несуществующего поста.

## Как запустить

1. Установи Python версии 3.8 или выше.
2. Установи зависимости:

   ```bash
   pip install pytest requests
   ```

3. Открой терминал в папке `autotests`.
4. Запусти тесты:

   ```bash
   python -m pytest -v
   ```
