# Postman Collection — JSONPlaceholder API Tests

Коллекция предназначена для тестирования REST API [JSONPlaceholder](https://jsonplaceholder.typicode.com/).

В коллекции представлены позитивные и негативные сценарии проверки API с использованием HTTP-методов GET, POST, PUT и DELETE.

## 1. Что входит в коллекцию

Коллекция содержит 6 запросов с автоматическими проверками на вкладке Scripts → Post-response.

| # | Метод | Endpoint | Что проверяется |
|---|---|---|---|
| 1 | GET | `/posts/1` | Статус 200, наличие поля userId, время ответа менее 1000 мс |
| 2 | GET | `/posts` | Статус 200, тип ответа — массив, количество элементов — 100 |
| 3 | POST | `/posts` | Статус 201, наличие поля id, соответствие title отправленному запросу |
| 4 | PUT | `/posts/1` | Статус 200, соответствие обновлённого title ожидаемому значению |
| 5 | DELETE | `/posts/1` | Статус 200 |
| 6 | GET | `/posts/101` | Негативный сценарий: статус 404, пустой объект в теле ответа |

## 2. Как запустить коллекцию

1. Скачай файл `JSONPlaceholder API Tests.postman_collection.json` из репозитория.
2. Открой Postman.
3. Нажми Import и выбери скачанный файл.
4. Открой импортированную коллекцию.
5. Нажми Run и запусти все запросы.
6. Проверь результаты выполнения автоматических тестов.

## 3. Используемые проверки

* Проверка HTTP-статусов ответа.
* Проверка структуры JSON.
* Проверка наличия обязательных полей.
* Проверка соответствия полученных данных ожидаемым значениям.
* Проверка времени ответа.
* Проверка обработки запроса к несуществующему ресурсу.

## 4. Особенности тестового API

JSONPlaceholder — учебный тестовый API.

Операции POST, PUT и DELETE имитируют создание, изменение и удаление ресурсов. Изменения не сохраняются на сервере как реальные данные.

## 5. Используемые навыки

* REST API и принципы взаимодействия клиент-сервер.
* HTTP-методы: GET, POST, PUT, DELETE.
* HTTP-статус-коды: 200, 201, 404.
* Формат данных JSON.
* Работа с Postman Collections.
* Написание автоматических проверок на JavaScript.
* Позитивное и негативное тестирование.
